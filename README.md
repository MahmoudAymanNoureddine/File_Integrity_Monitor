# File Integrity Monitor

## Overview
A Python-based File Integrity Monitoring (FIM) tool that uses SHA256 hashing to monitor critical files, detect modifications, generate alerts, assess risk levels, and create security reports.

## Features
- SHA256 File Hashing
- Baseline Creation
- File Change Detection
- Missing File Detection
- Risk Assessment
- Security Alerts
- JSON Report Generation
- Security Report Generation
- Multiple File Monitoring

## Technologies Used
- Python 3
- Hashlib
- JSON
- OS Module
- Datetime Module
